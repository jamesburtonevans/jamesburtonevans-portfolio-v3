# AGENTS.md

## Project Structure
This is a static HTML/CSS/JavaScript portfolio website with no build step required. The main entrypoint is `index.html`.

## Key Files
- `index.html` - Main homepage
- `work.html` - Work/project listing page
- `about.html` - About page
- `style.css` - All styling
- `components/nav-bar.js` - Navigation bar custom element
- `components/project-card.js` - Project card custom element

## How to View
Open `index.html` directly in a browser. No server or build process required.

## Framework/Libraries
- Pure vanilla HTML, CSS, JavaScript
- Custom web components (nav-bar, project-card)
- Font Awesome for icons
- Google Fonts for typography

## Developer Commands
- Open `index.html` in any modern browser to view
- No special commands needed - this is a static site

## Architecture Notes
- Uses custom HTML elements for reusable components
- Responsive design with CSS variables for theming
- No external dependencies beyond CDN-hosted libraries
